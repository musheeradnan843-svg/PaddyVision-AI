# PaddyVision AI Upgrade Roadmap

Project: 66.878 ha Sekinchan Paddy Digital-Twin Prototype  
Source of truth: `DATA_CONTRACT.md` and inspected repository/data files.  
Rule: Read this file and `DATA_CONTRACT.md` before each phase. After a phase is complete, mark it `[x] Completed` and record changed files plus key decisions here. Keep phases separate and explain implementation in simple Hinglish.

## Verified baseline and assessment

- The satellite panel contains temporal Sentinel-1/2 metrics plus static elevation and Global Surface Water history fields, but the current SQLite index only stores NDVI/NDMI/NDWI, VV/VH, S2 source and fill confidence.
- The current 3D satellite/soil surfaces are texture overlays on an illustrative field scene. Terrain relief is not needed for Phase 1; elevation and water-history should be map/texture overlays and carry honest scale/source descriptions.
- `bright_flag` and `s1_outlier_flag` are nullable quality indicators. Preserve blank/missing separately from 0 and 1.
- Window summary `usable_s2_or_s1` needs careful interpretation alongside row-level counts; do not silently equate rows in the panel with a usable window.
- No external or synthetic observations may be joined to the Sekinchan AOI as local measurements. Keep evidence classes and source/time/spatial support visible.

## Seven phases

- [x] **Phase 1 — Static satellite layers and quality flags. Completed.** Verified source fields/scales; added a separate `static_pixels` table, AOI-clipped static-layer API and 2D/3D texture overlays; temporal flags now remain nullable and are summarized without coercing missing values. No terrain exaggeration.
- [x] **Phase 2 — 3D pixel inspector. Completed.** Added hover preview and click-to-pin picking on the active satellite or soil texture. Raycast UVs are inverted through the same local projected canvas transform used to render the field; the nearest AOI source-cell centre is reported only within a half-cell-footprint tolerance. The inspector shows value, coordinate, date/depth, source/fill confidence, raw quality-flag state, and evidence class; nodata gaps do not become zero.
- [x] **Phase 3 — Derived management grid. Completed.** Added 50 m/100 m EPSG:32647 grid summaries for selected time-window Sentinel metrics and an AOI-clipped relative screen in the satellite explorer. Each source pixel centre is assigned once; zone means are compared to the selected window AOI mean in population-SD units. Zones with fewer than five values remain unclassified. UI/API explicitly identify derived zones, not cadastral plots, diagnoses, yield estimates, or prescriptions.
- [x] **Phase 4 — External UAV multispectral index lab. Completed.** Added in-memory processing of five aligned single-band TIFFs (`blue`, `green`, `red`, `red_edge`, `nir`) with deterministic NDVI/NDRE/GNDVI formulas, alignment checks, nodata masking, index previews, and full-resolution summary statistics. The UI labels the output `MODELLED_EXTERNAL`, notes the Arkansas RiceUAS domain and unverified reflectance calibration, and never maps the result on Sekinchan. The legacy yield CNN remains retired from local claims.
- [x] **Phase 5 — Illustrative UAV mission simulator. Completed.** Added assumed-parameter route generation in EPSG:32647, AOI-clipped swaths for the supplied convex boundary, a synthetic API response, and an explicitly labelled 3D footprint/route overlay with play/pause/clear controls. No flightability, measured coverage, or legal/operational claim.
- [x] **Phase 6 — Production engineering hygiene. Completed.** Added explicit version-tracked schema setup, a metadata-only segmentation run-history endpoint/UI, project `.env` loading and safe example, and a minimal API `requirements.txt` derived from active imports. Runtime package/database compatibility still needs to be confirmed in the user's configured API environment.
- [x] **Phase 7 — Bounded read-only Field Intelligence Agent. Completed.** Added a deterministic internal-tool router and dashboard question panel. Supported summaries cite the tool, source, evidence class, and uncertainty. Local yield claims, disease diagnosis, irrigation/soil prescriptions, and chemical advice are refused. Synthetic yield/water data is only shown when explicitly requested as a demo. No LLM, web access, or write/action tool is connected.

## Three audit corrections / guardrails

- [x] **Working-tree preservation:** At baseline, `README.md`, `api/main.py`, and `api/services/segmentation.py` were already modified. Their pre-existing changes were preserved while adding Phase 1.
- [x] **Water/elevation semantics:** TIFF descriptions confirm final bands 556–558 are `elevation_m`, `gsw_occurrence`, `gsw_seasonality`. The merged README documents elevation in metres from an approximately 30 m source model. GSW values observed in the panel are 0–5 and 0–3 respectively, but supplied TIFF/CSV metadata does not specify units or period; UI describes them as source values. No fake exaggerated terrain.
- [x] **Availability/flag semantics audited:** Eight summary rows have `usable_s2_or_s1=0`; six have nonzero S2 counts/rows, including `2025-311` (4,426 direct S2 pixels, 66.2% coverage). The source README does not define the flag sufficiently to explain the mismatch; the dashboard preserves and surfaces it instead of inventing a reason. Flags remain nullable; panel totals are `bright_flag`: 5,192 flagged / 602,693 clear / 98,509 blank; `s1_outlier_flag`: 362 flagged / 605,845 clear / 100,187 blank.
